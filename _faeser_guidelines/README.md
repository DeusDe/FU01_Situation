# Guided-Fallstudie — Web-UI-Prototyping

- **`prototyp/`** — der codierte Prototyp der Fallstudie. Öffnen Sie `prototyp/index.html` im Browser (keine
  Installation nötig).
- **`guided-fallstudie.md`** — Nachschlagewerk zu den HTML/CSS/Bootstrap-Grundlagen mit Fundstellen aus dem
  Prototyp und Links zu MDN bzw. zur Bootstrap-Dokumentation. Klappen Sie ein Konzept auf, wenn Sie es
  brauchen.
- **`howto_ui-zustaende.md`** / **`howto_responsive-strategie.md`** / **`howto_barrierefreiheit.md`** —
  ergänzende Cheat-Sheets, auf die die Guided-Fallstudie an mehreren Stellen verweist.
- **`kontrollfragen.md`** — Selbsttest-Fragen zu den fachlichen Inhalten der obigen Dokumente, zum
  Aufklappen der Lösung.
- **`kontrollfragen-quiz.html`** — interaktive Version derselben Fragen zum Öffnen im Browser: Multiple-Choice
  mit Sofort-Feedback, offene Fragen zum Aufdecken der Musterlösung, zufällige Reihenfolge, Themenauswahl.

Weitere Materialien zu dieser Lernsituation (Arbeitsaufträge, Bewertungskatalog, Wireframes,
Zustandsdiagramm …) werden im Unterricht über Teams verteilt und sind nicht Teil dieses Ordners.
